## Goal

构建一个前后端联动的「算法演示与导出平台」：后端 Java（零依赖 `com.sun.net.httpserver.HttpServer`）提供 HelloWorld / SHA-256 哈希 / 冒泡排序 三个算法接口与一个 CSV 导出接口；前端新增独立静态页 `demo.html`，三 tab 展示三种算法执行结果并提供导出按钮触发 CSV 下载。

## Architecture

后端采用轻量 JDK 内置 `HttpServer`（无 Spring、无构建工具，`javac` 直编直跑），按职责分包：`server/`（入口+路由+CORS+错误处理）、`service/`（三个算法 + 导出）、`util/`（零依赖 JSON 序列化）。前端为独立静态页，不纳入 Hexo 构建链，通过 `fetch` 调后端 HTTP API，导出用隐藏 `<a download>` 触发浏览器下载。跨库仅靠 4 个 HTTP 端点契约对齐，不修改两仓库任何现有文件（向后兼容）。

## Tech Stack

- 后端：Java 8+ 标准库（`com.sun.net.httpserver.HttpServer`、`java.security.MessageDigest`、`java.net.URLDecoder`）
- 前端：原生 HTML/CSS/JS（无框架），`fetch` API
- 构建：后端 `javac -encoding UTF-8`；前端无构建（直接静态文件）
- 验证：`curl` 端到端 + 浏览器手动验证

## Task 1: util/JsonUtil — 零依赖 JSON 序列化

**Files:**
- Create: `[leecode] datastruct/src/util/JsonUtil.java`

**Interfaces:**
- Consumes: 无
- Produces: `public static String toJson(java.util.LinkedHashMap<String,Object> map)` — 将有序 map 序列化为紧凑 JSON（无空格）；字符串值做基本转义（`"`、`\`、控制字符）；数字/布尔原样输出。

- [ ] **Step 1: 创建 `JsonUtil.java`**

```java
package util;

import java.util.LinkedHashMap;
import java.util.Map;

/**
 * 零依赖简易 JSON 序列化器。
 * 仅支持 String / Number / Boolean / null 值，保证插入顺序（LinkedHashMap）。
 */
public final class JsonUtil {

    private JsonUtil() {}

    public static String toJson(LinkedHashMap<String, Object> map) {
        StringBuilder sb = new StringBuilder("{");
        boolean first = true;
        for (Map.Entry<String, Object> e : map.entrySet()) {
            if (!first) sb.append(',');
            first = false;
            sb.append('"').append(escape(e.getKey())).append('"').append(':');
            appendValue(sb, e.getValue());
        }
        sb.append('}');
        return sb.toString();
    }

    private static void appendValue(StringBuilder sb, Object v) {
        if (v == null) {
            sb.append("null");
        } else if (v instanceof Number || v instanceof Boolean) {
            sb.append(v.toString());
        } else {
            sb.append('"').append(escape(v.toString())).append('"');
        }
    }

    private static String escape(String s) {
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            switch (c) {
                case '"':  sb.append("\\\""); break;
                case '\\': sb.append("\\\\"); break;
                case '\n': sb.append("\\n");  break;
                case '\r': sb.append("\\r");  break;
                case '\t': sb.append("\\t");  break;
                default:
                    if (c < 0x20) {
                        sb.append(String.format("\\u%04x", (int) c));
                    } else {
                        sb.append(c);
                    }
            }
        }
        return sb.toString();
    }

    /** 自测入口：验证序列化正确性。 */
    public static void main(String[] args) {
        LinkedHashMap<String, Object> m = new LinkedHashMap<>();
        m.put("result", "Hello World");
        m.put("timestamp", 1753872000000L);
        String json = toJson(m);
        System.out.println(json);
        // 期望输出：{"result":"Hello World","timestamp":1753872000000}
        if (!json.equals("{\"result\":\"Hello World\",\"timestamp\":1753872000000}")) {
            throw new AssertionError("JsonUtil 自测失败: " + json);
        }

        LinkedHashMap<String, Object> m2 = new LinkedHashMap<>();
        m2.put("input", "a\"b\\c");
        m2.put("ok", true);
        m2.put("n", null);
        String json2 = toJson(m2);
        System.out.println(json2);
        if (!json2.equals("{\"input\":\"a\\\"b\\\\c\",\"ok\":true,\"n\":null}")) {
            throw new AssertionError("JsonUtil 转义自测失败: " + json2);
        }
        System.out.println("JsonUtil 自测通过");
    }
}
```

## Task 3: service/HashService — SHA-256 哈希逻辑

**Files:**
- Create: `[leecode] datastruct/src/service/HashService.java`

**Interfaces:**
- Consumes: `util.JsonUtil.toJson(LinkedHashMap)`；`java.security.MessageDigest.getInstance("SHA-256")`
- Produces: `public static String execute(String input)` — 入参非空且长度 ≤ 1024 时返回 `{"input":"...","algorithm":"SHA-256","hash":"<64hex>","length":64}`；否则抛 `IllegalArgumentException`
- 异常契约：调用方（RouterHandler）捕获 `IllegalArgumentException` → HTTP 400 `{"error":"input is required"}`（空/缺失）或 `{"error":"input too long"}`（超长）

- [ ] **Step 1: 创建 `HashService.java`**

```java
package service;

import util.JsonUtil;
import java.security.MessageDigest;
import java.util.LinkedHashMap;

/**
 * 哈希算法服务：SHA-256。
 * 注意：与现有 datastruct/src/Hashtab/HashTabDemo.java（哈希表数据结构）无关，
 * 本类为独立的密码学哈希实现。
 */
public final class HashService {

    private static final int MAX_INPUT_LEN = 1024;

    private HashService() {}

    public static String execute(String input) {
        if (input == null || input.isEmpty()) {
            throw new IllegalArgumentException("input is required");
        }
        if (input.length() > MAX_INPUT_LEN) {
            throw new IllegalArgumentException("input too long");
        }
        try {
            MessageDigest md = MessageDigest.getInstance("SHA-256");
            byte[] digest = md.digest(input.getBytes("UTF-8"));
            String hex = toHexLower(digest);

            LinkedHashMap<String, Object> m = new LinkedHashMap<>();
            m.put("input", input);
            m.put("algorithm", "SHA-256");
            m.put("hash", hex);
            m.put("length", hex.length());
            return JsonUtil.toJson(m);
        } catch (java.security.NoSuchAlgorithmException | java.io.UnsupportedEncodingException e) {
            // JDK 保证 SHA-256 与 UTF-8 存在，理论不会到达
            throw new RuntimeException(e);
        }
    }

    private static String toHexLower(byte[] bytes) {
        StringBuilder sb = new StringBuilder(bytes.length * 2);
        for (byte b : bytes) {
            sb.append(Character.forDigit((b >> 4) & 0xF, 16));
            sb.append(Character.forDigit(b & 0xF, 16));
        }
        return sb.toString();
    }

    public static void main(String[] args) {
        // 标准向量：SHA-256("hello") 必须等于固定值
        String json = execute("hello");
        System.out.println(json);
        String expected = "2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824";
        if (!json.contains("\"hash\":\"" + expected + "\"") || !json.contains("\"length\":64")) {
            throw new AssertionError("HashService 标准向量自测失败: " + json);
        }
        // 空入参异常
        try {
            execute("");
            throw new AssertionError("空入参应抛异常");
        } catch (IllegalArgumentException ex) {
            if (!"input is required".equals(ex.getMessage())) {
                throw new AssertionError("异常消息不符: " + ex.getMessage());
            }
        }
        // 超长入参异常
        StringBuilder big = new StringBuilder();
        for (int i = 0; i < 1025; i++) big.append('a');
        try {
            execute(big.toString());
            throw new AssertionError("超长入参应抛异常");
        } catch (IllegalArgumentException ex) {
            if (!"input too long".equals(ex.getMessage())) {
                throw new AssertionError("异常消息不符: " + ex.getMessage());
            }
        }
        System.out.println("HashService 自测通过");
    }
}
```

## Task 4: service/BubbleSortService — 冒泡排序逻辑

**Files:**
- Create: `[leecode] datastruct/src/service/BubbleSortService.java`
- 参考（只读，不修改）: `[leecode] datastruct/src/排序/冒泡排序.java`

**Interfaces:**
- Consumes: `util.JsonUtil.toJson(LinkedHashMap)`
- Produces: `public static String execute(int[] data)` — 返回 `{"input":[...],"sorted":[...],"steps":<交换次数>,"asc":true}`；`data` 为 null 或空抛 `IllegalArgumentException`
- 设计约束（相对现有 `冒泡排序.java` 的改进）：
  - 现有 `冒泡排序.java` 用 `static int temp` 共享静态字段（非线程安全），本类**改用局部 `temp`**。
  - 现有不统计交换次数，本类**新增 `steps` 计数**。
  - 不直接 import 现有类（规避中文包名 `排序` 路径编译问题），逻辑就地重写。

- [ ] **Step 1: 创建 `BubbleSortService.java`**

```java
package service;

import util.JsonUtil;
import java.util.LinkedHashMap;

/**
 * 冒泡排序服务（升序）。
 * 逻辑参考 datastruct/src/排序/冒泡排序.java，改进点：
 * 1) temp 改为局部变量（线程安全）；
 * 2) 统计交换次数 steps；
 * 3) 返回结构化 JSON 而非控制台打印。
 * 不直接 import 现有类（规避中文包名路径编译问题）。
 */
public final class BubbleSortService {

    private BubbleSortService() {}

    public static String execute(int[] data) {
        if (data == null || data.length == 0) {
            throw new IllegalArgumentException("data is required");
        }
        // 复制一份，避免修改入参
        int[] sorted = new int[data.length];
        System.arraycopy(data, 0, sorted, 0, data.length);

        int steps = 0;
        // 经典冒泡（升序）
        for (int i = 0; i < sorted.length; i++) {
            for (int j = 0; j < sorted.length - i - 1; j++) {
                if (sorted[j] > sorted[j + 1]) {
                    int temp = sorted[j];
                    sorted[j] = sorted[j + 1];
                    sorted[j + 1] = temp;
                    steps++;
                }
            }
        }

        LinkedHashMap<String, Object> m = new LinkedHashMap<>();
        m.put("input", toJsonArray(data));
        m.put("sorted", toJsonArray(sorted));
        m.put("steps", steps);
        m.put("asc", true);
        return JsonUtil.toJson(m);
    }

    private static String toJsonArray(int[] arr) {
        StringBuilder sb = new StringBuilder("[");
        for (int i = 0; i < arr.length; i++) {
            if (i > 0) sb.append(',');
            sb.append(arr[i]);
        }
        sb.append(']');
        return sb.toString();
    }

    public static void main(String[] args) {
        // PRD 示例向量：5,3,8,1 → 排序后 1,3,5,8
        int[] data = {5, 3, 8, 1};
        String json = execute(data);
        System.out.println(json);
        if (!json.contains("\"sorted\":[1,3,5,8]")) {
            throw new AssertionError("BubbleSortService 排序结果自测失败: " + json);
        }
        // 空入参异常
        try {
            execute(null);
            throw new AssertionError("null 入参应抛异常");
        } catch (IllegalArgumentException ex) {
            if (!"data is required".equals(ex.getMessage())) {
                throw new AssertionError("异常消息不符: " + ex.getMessage());
            }
        }
        // 已排序数组 steps 应为 0
        int[] sorted = {1, 2, 3};
        String json2 = execute(sorted);
        if (!json2.contains("\"steps\":0")) {
            throw new AssertionError("已排序数组 steps 应为 0: " + json2);
        }
        System.out.println("BubbleSortService 自测通过");
    }
}
```

## Task 5: service/ExportService — CSV 导出逻辑

**Files:**
- Create: `[leecode] datastruct/src/service/ExportService.java`

**Interfaces:**
- Consumes: `HelloWorldService.execute()`、`HashService.execute(String)`、`BubbleSortService.execute(int[])`；`util.JsonUtil`
- Produces: `public static byte[] execute(String tab)` — 返回 CSV 字节流（UTF-8）；`tab` 非法（非 `helloworld`/`hash`/`bubble`）抛 `IllegalArgumentException`
- 导出语义：后端用固定示例入参生成结果再序列化 CSV（hash 用 `hello`，bubble 用 `5,3,8,1`），避免无参。
- CSV 格式：首行 `field,value`，后续每行 `字段名,值`；含逗号/引号的值用双引号包裹并转义内部引号。

- [ ] **Step 1: 创建 `ExportService.java`**

```java
package service;

import java.io.ByteArrayOutputStream;
import java.io.OutputStreamWriter;
import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.util.LinkedHashMap;
import java.util.Map;

/**
 * 导出服务：将各 tab 的算法结果序列化为 CSV（UTF-8）。
 * 导出时使用固定示例入参，避免无参端点。
 */
public final class ExportService {

    private ExportService() {}

    public static byte[] execute(String tab) {
        if (tab == null) {
            throw new IllegalArgumentException("invalid tab");
        }
        // 解析算法结果为 key-value 行
        Map<String, String> rows;
        String filename;
        switch (tab) {
            case "helloworld":
                rows = parseSimpleRows(HelloWorldService.execute());
                filename = "helloworld.csv";
                break;
            case "hash":
                rows = parseSimpleRows(HashService.execute("hello"));
                filename = "hash.csv";
                break;
            case "bubble":
                rows = parseSimpleRows(BubbleSortService.execute(new int[]{5, 3, 8, 1}));
                filename = "bubble.csv";
                break;
            default:
                throw new IllegalArgumentException("invalid tab");
        }
        return toCsv(rows).getBytes(StandardCharsets.UTF_8);
        // filename 由 RouterHandler 写入 Content-Disposition，本方法仅返回字节流
    }

    /** 解析 {\"k\":\"v\",...} 形式的简单 JSON 为有序键值对（值仅 String/Number/Boolean）。 */
    private static Map<String, String> parseSimpleRows(String json) {
        Map<String, String> rows = new LinkedHashMap<>();
        // 极简手写解析：去掉首尾 { }，按 "," 分段（值内不含未转义逗号，本场景安全）
        String body = json.trim();
        if (body.startsWith("{")) body = body.substring(1);
        if (body.endsWith("}")) body = body.substring(0, body.length() - 1);
        // 用状态机切分键值对
        int i = 0;
        while (i < body.length()) {
            // 读 key
            if (body.charAt(i) != '"') { i++; continue; }
            int keyEnd = body.indexOf('"', i + 1);
            String key = body.substring(i + 1, keyEnd);
            int colon = body.indexOf(':', keyEnd + 1);
            i = colon + 1;
            // 读 value
            String value;
            if (body.charAt(i) == '"') {
                int valEnd = body.indexOf('"', i + 1);
                value = body.substring(i + 1, valEnd);
                i = valEnd + 1;
                // 跳过逗号
                if (i < body.length() && body.charAt(i) == ',') i++;
            } else {
                int comma = body.indexOf(',', i);
                int end = (comma == -1) ? body.length() : comma;
                value = body.substring(i, end).trim();
                i = end;
                if (i < body.length() && body.charAt(i) == ',') i++;
            }
            rows.put(key, value);
        }
        return rows;
    }

    private static String toCsv(Map<String, String> rows) {
        StringBuilder sb = new StringBuilder();
        sb.append("field,value\r\n");
        for (Map.Entry<String, String> e : rows.entrySet()) {
            sb.append(csvCell(e.getKey())).append(',')
              .append(csvCell(e.getValue())).append("\r\n");
        }
        return sb.toString();
    }

    private static String csvCell(String s) {
        if (s.contains(",") || s.contains("\"") || s.contains("\n") || s.contains("\r")) {
            return "\"" + s.replace("\"", "\"\"") + "\"";
        }
        return s;
    }

    public static void main(String[] args) throws Exception {
        byte[] csv = execute("bubble");
        String text = new String(csv, StandardCharsets.UTF_8);
        System.out.println(text);
        if (!text.startsWith("field,value\r\n") || !text.contains("sorted") || !text.contains("steps")) {
            throw new AssertionError("ExportService bubble CSV 自测失败:\n" + text);
        }
        byte[] csv2 = execute("hash");
        String t2 = new String(csv2, StandardCharsets.UTF_8);
        System.out.println(t2);
        if (!t2.contains("2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824")) {
            throw new AssertionError("ExportService hash CSV 自测失败:\n" + t2);
        }
        try {
            execute("unknown");
            throw new AssertionError("非法 tab 应抛异常");
        } catch (IllegalArgumentException ex) {
            if (!"invalid tab".equals(ex.getMessage())) {
                throw new AssertionError("异常消息不符: " + ex.getMessage());
            }
        }
```

**Files:**

**Interfaces:**

- Produces: HTTP 服务，监听 `127.0.0.1:8080`，路由 4 端点 + OPTIONS 预检，统一 CORS、统一错误处理。
- 跨库契约对齐点（前端依赖）：`/api/helloworld`、`/api/hash?input=`、`/api/bubble?data=`、`/api/export?tab=`，baseURL `http://127.0.0.1:8080`。

- [ ] **Step 1: 创建 `RouterHandler.java`**

```java
package server;

import com.sun.net.httpserver.HttpExchange;
import com.sun.net.httpserver.HttpHandler;
import service.BubbleSortService;
import service.ExportService;
import service.HashService;
import service.HelloWorldService;
import util.JsonUtil;

import java.io.IOException;
import java.io.OutputStream;
import java.net.URLDecoder;
import java.util.LinkedHashMap;
import java.util.regex.Matcher;
import java.util.regex.Pattern;

/**
 * 路由分发器：统一 CORS、统一错误处理。
 * 响应约定：
 *  - 算法接口：application/json; charset=utf-8
 *  - 导出接口：text/csv; charset=utf-8
 *  - 错误：HTTP 4xx，body {"error":"<message>"}
 */
public class RouterHandler implements HttpHandler {

    private static final Pattern QUERY_PARAM = Pattern.compile("(?:^|&)([^=&]*)=([^&]*)");

    @Override
    public void handle(HttpExchange exchange) throws IOException {
        // 统一 CORS（对所有请求，含 OPTIONS 与错误响应）
        exchange.getResponseHeaders().set("Access-Control-Allow-Origin", "*");
        exchange.getResponseHeaders().set("Access-Control-Allow-Methods", "GET, OPTIONS");
        exchange.getResponseHeaders().set("Access-Control-Allow-Headers", "Content-Type");

        String method = exchange.getRequestMethod();
        String path = exchange.getRequestURI().getPath();

        // OPTIONS 预检：直接 204
        if ("OPTIONS".equals(method)) {
            exchange.sendResponseHeaders(204, -1);
            return;
        }
        if (!"GET".equals(method)) {
            sendError(exchange, 405, "method not allowed");
            return;
        }

        try {
            switch (path) {
                case "/api/helloworld":
                    sendJson(exchange, 200, HelloWorldService.execute());
                    break;
                case "/api/hash": {
                    String input = getQueryParam(exchange, "input");
                    sendJson(exchange, 200, HashService.execute(input));
                    break;
                }
                case "/api/bubble": {
                    int[] data = parseData(getQueryParam(exchange, "data"));
                    sendJson(exchange, 200, BubbleSortService.execute(data));
                    break;
                }
                case "/api/export": {
                    String tab = getQueryParam(exchange, "tab");
                    byte[] csv = ExportService.execute(tab);
                    sendCsv(exchange, tab, csv);
                    break;
                }
                default:
                    sendError(exchange, 404, "not found");
            }
        } catch (IllegalArgumentException e) {
            sendError(exchange, 400, e.getMessage());
        } catch (Exception e) {
            sendError(exchange, 500, "internal error");
        }
    }

    private static String getQueryParam(HttpExchange exchange, String name) throws IOException {
        String query = exchange.getRequestURI().getRawQuery();
        if (query == null) return null;
        Matcher m = QUERY_PARAM.matcher(query);
        while (m.find()) {
            if (name.equals(m.group(1))) {
                return URLDecoder.decode(m.group(2), "UTF-8");
            }
        }
        return null;
    }

    private static int[] parseData(String data) {
        if (data == null || data.isEmpty()) {
            throw new IllegalArgumentException("data format invalid");
        }
        String[] parts = data.split(",");
        if (parts.length < 1 || parts.length > 50) {
            throw new IllegalArgumentException("data format invalid");
        }
        int[] arr = new int[parts.length];
        for (int i = 0; i < parts.length; i++) {
            try {
                int v = Integer.parseInt(parts[i].trim());
                if (v < -1000 || v > 1000) {
                    throw new IllegalArgumentException("data format invalid");
                }
                arr[i] = v;
            } catch (NumberFormatException e) {
                throw new IllegalArgumentException("data format invalid");
            }
        }
        return arr;
    }

    private static void sendJson(HttpExchange exchange, int status, String body) throws IOException {
        byte[] bytes = body.getBytes("UTF-8");
        exchange.getResponseHeaders().set("Content-Type", "application/json; charset=utf-8");
        exchange.sendResponseHeaders(status, bytes.length);
        try (OutputStream os = exchange.getResponseBody()) {
            os.write(bytes);
        }
    }

    private static void sendCsv(HttpExchange exchange, String tab, byte[] csv) throws IOException {
        exchange.getResponseHeaders().set("Content-Type", "text/csv; charset=utf-8");
        exchange.getResponseHeaders().set("Content-Disposition",
                "attachment; filename=\"" + tab + ".csv\"");
        exchange.sendResponseHeaders(200, csv.length);
        try (OutputStream os = exchange.getResponseBody()) {
            os.write(csv);
        }
    }

    private static void sendError(HttpExchange exchange, int status, String message) throws IOException {
        LinkedHashMap<String, Object> m = new LinkedHashMap<>();
        m.put("error", message);
        byte[] bytes = JsonUtil.toJson(m).getBytes("UTF-8");
        exchange.getResponseHeaders().set("Content-Type", "application/json; charset=utf-8");
        exchange.sendResponseHeaders(status, bytes.length);
        try (OutputStream os = exchange.getResponseBody()) {
            os.write(bytes);
        }
    }
}
```

```javascript

let currentTab = 'hello';

document.addEventListener('DOMContentLoaded', () => {

  document.getElementById('bubble-run').addEventListener('click', runBubble);

function initTabs() {
  const tabs = [
    { btn: 'tab-hello', panel: 'panel-hello', name: 'hello' },
    { btn: 'tab-hash', panel: 'panel-hash', name: 'hash' },
    { btn: 'tab-bubble', panel: 'panel-bubble', name: 'bubble' },
  ];
  tabs.forEach(t => {
    document.getElementById(t.btn).addEventListener('click', () => {
      tabs.forEach(x => {
        document.getElementById(x.btn).classList.remove('active');
        document.getElementById(x.panel).classList.remove('active');
      });
      document.getElementById(t.btn).classList.add('active');
      document.getElementById(t.panel).classList.add('active');
      currentTab = t.name;
    });
  });

async function loadHello() {
  try {
    const res = await fetch(`${BASE_URL}/api/helloworld`);
    const data = await res.json();
    document.getElementById('hello-result').textContent = data.result;
    document.getElementById('hello-timestamp').textContent = data.timestamp;
  } catch (e) {
    document.getElementById('hello-result').textContent = '加载失败：' + e.message;
  }
}

async function runHash() {
  const input = document.getElementById('hash-input').value;
  try {
    const res = await fetch(`${BASE_URL}/api/hash?input=${encodeURIComponent(input)}`);
    const data = await res.json();
    if (res.ok) {
      document.getElementById('hash-result').textContent = data.hash;
      document.getElementById('hash-algorithm').textContent = data.algorithm;
      document.getElementById('hash-length').textContent = data.length;
    } else {
      document.getElementById('hash-result').textContent = '错误：' + data.error;
    }
  } catch (e) {
    document.getElementById('hash-result').textContent = '请求失败：' + e.message;
  }
}

async function runBubble() {
  const data = document.getElementById('bubble-input').value;
  try {
    const res = await fetch(`${BASE_URL}/api/bubble?data=${encodeURIComponent(data)}`);
    const json = await res.json();
    if (res.ok) {
      document.getElementById('bubble-input-display').textContent = JSON.stringify(json.input);
      document.getElementById('bubble-sorted').textContent = JSON.stringify(json.sorted);
      document.getElementById('bubble-steps').textContent = json.steps;
    } else {
      document.getElementById('bubble-sorted').textContent = '错误：' + json.error;
    }
  } catch (e) {
    document.getElementById('bubble-sorted').textContent = '请求失败：' + e.message;
  }
}

function exportCurrent() {
  // 隐藏 <a download> 触发浏览器下载
  const a = document.createElement('a');
  a.href = `${BASE_URL}/api/export?tab=${encodeURIComponent(currentTab)}`;
```

| 错误体 | `{"error":"<msg>"}` + HTTP 4xx | 前端读 `data.error` | ✅ 一致 |
| 导出下载 | `Content-Disposition: attachment; filename="<tab>.csv"` | `<a download="<tab>.csv">` | ✅ 一致 |

## 兼容性原则

- 契约仅「新增」，不修改两仓库任何现有文件（向后兼容）。
- 后端 `server/service/util` 全新 ASCII 包，不触碰现有中文包目录（`排序/`、`Hashtab/` 等）。
- 前端 `demo.html`/`js/demo.js`/`css/demo.css` 为根目录独立新增，不纳入 Hexo 构建，不修改 `index.html` 与主题脚本。
- 前端 baseURL 集中在 `demo.js` 顶部常量，便于环境切换。

## 风险与降级

| 风险 | 影响 | 缓解/降级 |
|---|---|---|
| 后端 HttpServer 不支持高并发 | 本地演示无影响 | 非目标，不做并发优化 |
| 前端 GitHub Pages 调本地 127.0.0.1 失败 | 线上页面无法调通后端 | PRD 明确后端地址为本地；线上仅展示静态结构，需用户本地起后端 |

| `com.sun.net.httpserver` 为非公开 API | JDK 8+ 可用，未来 JDK 可能变化 | 本期明确 JDK 8+；非目标不做替代方案 |
